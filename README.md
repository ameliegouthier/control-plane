# Control Plane / Automation Governance

SaaS dashboard that audits automation workflows (n8n, Zapier, Make, Airtable). UI inspired by modern developer tools (Linear, Vercel).

## Project root

**Run all commands from the repository root** (this directory), not from `app/`.

- **Install:** `npm install`
- **Dev:** `npm run dev`
- **Build:** `npm run build` (uses webpack; Turbopack disabled for Tailwind v4 compatibility)
- **Start:** `npm run start`

Single `package.json` and `package-lock.json` live at the repo root. Source code is in `src/` (Next.js app, components, lib, types, styles).
